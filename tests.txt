Тест 1:
Ввод: 2 3; 4 -2 7; 1 0 3
Ожидаемый результат: Row 0 sum = 9, Row 1 sum = 4; Total = 13; транспонированная 3x2
Фактический результат: Row 0 sum = 9, Row 1 sum = 4; Total = 13; Transposed 3x2

Тест 2:
Ввод: 1 1; -5
Ожидаемый результат: rowSum -5; total -5; транспонированная [-5]
Фактический результат: Row 0 sum = -5; Total = -5; Transposed [-5]

Тест 3:
Ввод: 1 3; 2 0 -2
Ожидаемый результат: rowSum 0; total 0; результат 3 строки: 2, 0, -2
Фактический результат: Row 0 sum = 0; Total = 0; Transposed 3x1 (2, 0, -2)

Тест 4:
Ввод: 3 1; 1 2 3
Ожидаемый результат: rowSum 1, 2, 3; total 6; результат одна строка 1 2 3
Фактический результат: Row 0 sum = 1, Row 1 sum = 2, Row 2 sum = 3; Total = 6; Transposed 1x3 (1 2 3)

Тест 5:
Ввод: 2 2; 0 0; 0 0
Ожидаемый результат: Все суммы нулевые; форма 2 на 2 сохраняется
Фактический результат: Row 0 sum = 0, Row 1 sum = 0; Total = 0; Transposed 2x2

Тест 6:
Ввод: 5 5; все элементы 1000
Ожидаемый результат: Каждая строка 5000; total 25000; результат 5 на 5
Фактический результат: Каждая строка 5000; Total = 25000; Transposed 5x5

Тест 7 (ошибочные данные):
Ввод: 0 3 (или 2 6) / abc / 1 1; -1001

Фактический результат: Size error / Input error / Value error
