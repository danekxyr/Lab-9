# Лабораторная работа № 9

* **Студент:** Пылинский Даниил Максимович
* **Группа:** ПИ 1-1
* **Тема:** Двумерные массивы и обработка матриц

## Назначение файлов проекта

* **`main.c`** — ввод матрицы размером от `1x1` до `5x5` с элементами `[-1000, 1000]`, вывод матрицы, расчёт суммы каждой строки, общей суммы элементов и транспонирование матрицы.
* **`self.c`** — вычисление суммы каждого столбца матрицы и поиск индекса первой строки с наименьшей суммой элементов.
* **`tests.txt`** — протокол обязательных тестов с входными данными, ожидаемыми и фактическими результатами.

## Команды сборки (PowerShell / Bash)

```bash
gcc -Wall -Wextra -std=c11 main.c -o lab9_main
gcc -Wall -Wextra -Wpedantic -std=c11 self.c -o lab9_self
```

## Пример запуска

### Основная программа (`main.c`)
Ввод:
```text
2 3
4 -2 7
1 0 3
```
Вывод:
```text
Row 0 sum = 9
Row 1 sum = 4
Total = 13
Transposed:
     4     1
    -2     0
     7     3
```

### Самостоятельная работа (`self.c`)
Ввод:
```text
2 3
4 -2 7
1 0 3
```
Вывод:
```text
Column sums: 5 -2 10
Min row index = 1
Min row sum = 4
```
